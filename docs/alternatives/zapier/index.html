Open source alternatives to Zapier

Connect apps with trigger-action automations. If the subscription is the problem, these do the same job and you keep the data.

Fair-code workflow automation platform with native AI capabilities. Combine visual building with custom code, self-host or cloud, 400+ integrations.

Scripts as workflows; better when automation is really engineering.
