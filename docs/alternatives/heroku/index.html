Open source alternatives to Heroku

Platform-as-a-service with git push deploys. If the subscription is the problem, these do the same job and you keep the data.

coolify

More modern UI and broader support than Dokku.

65.3k stars · PHP · Apache-2.0

An open-source, self-hostable PaaS alternative to Vercel, Heroku & Netlify that lets you easily deploy static sites, databases, full-stack applications and 360+ one-click services on your own servers.

dokku

Closest match: git push to deploy, buildpacks, single server.

32.2k stars · Go · MIT

A docker-powered PaaS that helps you build and manage the lifecycle of applications

caprover

Easiest to hand to a non-DevOps teammate.

15.2k stars · TypeScript · custom licence

Scalable PaaS (automated Docker+nginx) - aka Heroku on Steroids
