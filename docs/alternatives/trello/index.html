Open source alternatives to Trello

Kanban boards with cards, lists and simple automation. If the subscription is the problem, these do the same job and you keep the data.

focalboard

Boards that live next to your chat; good if you already run Mattermost.

26.5k stars · TypeScript · custom licence

Focalboard is an open source, self-hosted alternative to Trello, Notion, and Asana.

wekan

The original open source kanban. Swimplanes, checklists, integrations.

21.1k stars · JavaScript · MIT

FLOSS kanban, built with Meteor. Official Public Support at GitHub issues only. Official Private Pre-Paid Support at https://wekan.fi/commercial-support/ only. Translation PRs to imports/i18n/data/en.i18n.json, other translations at https://app.transifex.com/wekan/wekan . No telemetry.

planka

Closest Trello clone: boards, lists, cards, real-time updates.

12.7k stars · JavaScript · custom licence

Elegant open source project tracking. Self-hosted Kanban for teams — free Community edition, with PLANKA Pro for organisations.

vikunja

Kanban plus Gantt and calendar views; more than a board.

5.9k stars · Go · AGPL-3.0

The task manager you actually own.
