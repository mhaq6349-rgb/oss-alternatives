# OpenAlt

A programmatic SEO site: open source alternatives to the tools people already pay for.

**Live:** https://mhaq6349-rgb.github.io/oss-alternatives/
**Status:** deployed. 49 products, 101 projects, 171 pages.

## Why this niche

The search demand is real and specific — people type "open source alternative to Notion", not "open source productivity tools". Every page targets one of those queries exactly, so there is no keyword guessing.

The data is free and reliable: the GitHub API returns stars, license, language and last activity for every project. Nothing is scraped, nothing is invented, and every claim on a page is either editorial (the one-line "why") or fetched.

## Structure

```
data/tools.json      curated list: commercial tool -> open source alternatives
data/repos.json      GitHub metadata cache, refreshed by fetch_github.py
scripts/fetch_github.py  pulls /repos/{owner}/{repo} for every cited project
scripts/build.py     renders the whole site into site/
assets/style.css     one stylesheet, no framework
site/                generated output (gitignored)
```

## Build

```bash
python scripts/fetch_github.py     # cache GitHub metadata
python scripts/build.py            # render site/
python -m http.server 8123 --directory site
```

`fetch_github.py` uses the token at `~/.config/opencode/github-token.txt` (5,000 req/hr). Without it you get 60/hr, which is enough for this dataset but not for a large one.

## Page types

| Page | URL | Count |
|---|---|---|
| Home | `/` | 1 |
| Commercial tool | `/alternatives/{tool}/` | 4 |
| Category | `/category/{category}/` | 4 |

Each tool page carries editorial notes, a star-sorted card grid, and a comparison table. Each project page links back to every tool it replaces, which builds the internal link graph both ways.

Generated alongside the HTML: `sitemap.xml` and `robots.txt`.

## Deploy

GitHub Pages serves `docs/` from `main`. Build, then commit `docs/` and push.

```bash
python scripts/fetch_github.py
python scripts/build.py
git add -A && git commit -m "rebuild" && git push
```

## What was verified

- 171 pages build from 101 live GitHub records, 3,348,886 combined stars.
- Every page loads with zero console errors, locally and live.
- Stylesheet resolves correctly at all three depths (`/`, `/alternatives/x/`, `/projects/o/r/`).
- `/`, a tool page, a project page, a category page, `sitemap.xml`, `robots.txt` and the stylesheet all return 200 from the deployed host.

Bugs found and fixed during the build:

1. **Link depth was off by one.** Subpages requested `/alternatives/assets/style.css` and rendered completely unstyled. Caught by reading the access log, not by eye.
2. **`NOASSERTION` leaked into the UI.** AFFiNE, NocoDB, Baserow and Teable use modified licences that GitHub cannot identify. Now rendered as "custom licence" with an explanation, rather than looking like a data failure.

## The audit subsite

`/audit/` is a seven-page service site for the paid audit offer: home, method, worked example, pricing, questions, about, contact. Generated by `scripts/build_audit.py` into `docs/audit/`, which `build.py` calls at the end.

```
audit/assets/site.css   shared stylesheet
audit/assets/site.js    ledger reveal, running total, calculator
scripts/build_audit.py  page generator and copy
```

Design notes: greenbar accounting paper instead of the usual dark landing page, IBM Plex Mono reserved for figures, and one deliberate motion — the ledger prints line by line while a fixed rail counts the savings.
